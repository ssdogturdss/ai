# Deploy this app

This repo includes a `Dockerfile` and `docker-compose.yml` generated by [Clownin](https://github.com/clownin).
Any platform that runs Docker containers can host it in under a minute.
The project-owned `DATABASE_URL` must be configured as a host or CI secret;
never commit it to this repository.

---

## Railway (recommended — free tier available)

1. Go to **[railway.app/new](https://railway.app/new)** → click **Deploy from GitHub repo**
2. Select this repo from the list
3. Railway auto-detects the Dockerfile and deploys — your URL appears in the dashboard

---

## Render

1. Go to **[dashboard.render.com/web/new](https://dashboard.render.com/web/new)**
2. Connect your GitHub account → select this repo
3. Render detects the Dockerfile → click **Create Web Service**

---

## Fly.io (auto-deploy via GitHub Actions)

A `.github/workflows/fly-deploy.yml` and `fly.toml` are included in this repo.
Every push to `main` deploys automatically — no CLI needed.

**Setup (one time):**
1. Create a Fly.io account at [fly.io](https://fly.io) and create a new app in their dashboard
2. Open `fly.toml` in this repo and replace `your-app-name` with your actual Fly.io app name
3. Generate an API token: Fly.io dashboard → **Account** → **Access Tokens** → **Create token**
4. Add it to your GitHub repo: **Settings** → **Secrets and variables** → **Actions** → **New secret**
   - Name: `FLY_API_TOKEN`
   - Value: your token
5. When this project is exported from Clownin, its `DATABASE_URL` Actions secret is configured automatically
6. Push to `main` — your app deploys automatically to `<app>.fly.dev`
